# To-Do List на Sass и ванильном JavaScript с упором на адаптивность и доступность интерфейса.

Группа: **ФИТ-241**

## О проекте

Одностраничное приложение для списка дел. Данные хранятся в `localStorage`, поэтому задачи и выбранная тема сохраняются после перезагрузки страницы.

**Возможности**

- добавление (кнопка открывает модальное окно), редактирование (тоже в модальном окне), отметка выполненной и удаление задачи (с подтверждением);
- выполненные задачи зачёркиваются и уходят вниз списка;
- поиск по названию и фильтры «Все / Активные / Готовые»;
- счётчик оставшихся задач и сообщение о пустом списке;
- светлая и тёмная темы; при первом визите берётся системная (`prefers-color-scheme`), выбор пользователя запоминается;
- адаптивная вёрстка (mobile-first, брейкпоинты `480 / 768 / 1024 px`).

**Доступность (a11y)**

- семантическая разметка (`header`, `main`, `section`, `form`, `ul`, `dialog`);
- у всех полей есть `label` (в поиске — скрытый через миксин `visually-hidden`);
- кнопки-иконки подписаны через `aria-labelledby` (собственный `aria-label` + `id` названия задачи), переключатель темы и фильтры — `aria-pressed`;
- действия озвучиваются скринридеру через live-область `role="status"`; ошибки валидации — через `role="alert"` и `aria-invalid`;
- полная работа с клавиатуры, видимый `:focus-visible`, ссылка «Перейти к списку задач»;
- модальные окна на нативном `<dialog>`: фокус удерживается внутри, закрытие по `Esc`, фокус возвращается на кнопку;
- контрастные цвета в обеих темах;
- учитывается `prefers-reduced-motion`.

## Структура

```
todo-list/
├─ sass/
│  ├─ utils/        # переменные, функции (rem, space), миксины (up, visually-hidden, focus-ring)
│  ├─ base/         # reset, типографика, вспомогательные классы
│  ├─ layout/       # container, header, main/toolbar
│  ├─ components/   # button, task-form, search, task, modal, theme-switcher
│  ├─ themes/       # light и dark (CSS-переменные)
│  └─ main.scss     # точка входа
├─ js/main.js
├─ dist/            # собранный CSS (в .gitignore)
├─ index.html
├─ package.json
├─ package-lock.json
├─ README.md
└─ .gitignore
```

Именование классов — БЭМ (`task__title`, `btn--primary`). Модули подключаются через `@use` / `@forward`.

## Зависимости

- [Node.js](https://nodejs.org/) 18+ и npm
- `sass` — компиляция SCSS в CSS (devDependency)
- `serve` — простой статический сервер (devDependency)


## Запуск

```bash
npm install     # установить зависимости
npm start       # собрать CSS в dist/main.css и запустить сервер
```

Откройте адрес, который покажет `serve` (обычно <http://localhost:3000>).

Другие команды:

| Команда         | Что делает                                       |
| --------------- | ------------------------------------------------ |
| `npm run build` | разовая сборка `scss/main.scss` → `dist/main.css` |
| `npm run sass:dev` | пересборка CSS при каждом изменении SCSS      |
| `npm run serve` | только сервер (CSS должен быть уже собран)       |

> Папка `dist/` не хранится в репозитории, поэтому после клонирования обязательно выполните `npm run build` (или `npm start`).
